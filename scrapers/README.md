# Kalis Academic Data Scrapers 🕷️

תיקייה זו מיועדת לכלי סריקה (Scrapers) ואיסוף נתונים פנימיים עבור מוסדות אקדמיים בישראל.

### ⚠️ דגשים חשובים:
- הקוד בתיקייה זו הוא **כלי פנימי בלבד (CLI Tool)** לאיסוף נתונים ואינו חלק מקוד ה-Frontend או ה-API של האתר המונגש לגולשים.
- כל סקריפר מיועד למוסד אקדמי ספציפי ושומר את התוצאות לקובץ נתונים מנומל.

### סקריפרים קיימים:
- `scrapers/tau.ts`: סורק את קטלוג התארים ודרישות הסכם מתוך האתר הרשמי של אוניברסיטת תל אביב (`go.tau.ac.il`).

### הרצה:
```bash
npx tsx scrapers/tau.ts
```
