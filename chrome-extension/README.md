# 🎓 תוסף כרום: מתקבלים — אימות סכם אוטומטי (Kalis AutoFill)

תוסף כרום רשמי של פלטפורמת **מתקבלים**, המאפשר להזין אוטומטית בלחיצה אחת את כל ציוני הבגרות והפסיכומטרי המוצעים ישירות למחשבוני הסכם הרשמיים של 8 האוניברסיטאות בישראל (הטכניון, תל אביב, העברית, בן-גוריון, בר-אילן, חיפה, אריאל ורייכמן).

---

## 🚀 איך להתקין את התוסף בדפדפן כרום / Edge תוך 20 שניות:

1. פתח את דפדפן **Google Chrome** (או Microsoft Edge / Brave).
2. בשורת הכתובת, היכנס ל:
   ```text
   chrome://extensions
   ```
3. בפינה הימנית העליונה (או השמאלית, תלוי בשפת הדפדפן), הפעל את המתג: **"מצב מפתח" (Developer mode)**.
4. לחץ על הכפתור: **"טעינת תוסף לא ארוז" (Load unpacked)**.
5. בחר בתיקייה זו:
   ```text
   /Users/sagikats/Desktop/kalis/chrome-extension
   ```
6. **זה הכל!** התוסף מותקן כעת בדפדפן ומוכן לשימוש מיידי.

---

## 🎯 איך לבדוק את זה בלייב:
1. פתח את אתר מתקבלים בלוקלהוסט: [http://localhost:3000/flow](http://localhost:3000/flow)
2. עבור לשלב 4 (המסלולים המומלצים).
3. לחץ על **"הזנה אוטומטית במחשבון [המוסד] ⚡"**.
4. לשונית של אתר האוניברסיטה (למשל הטכניון) תיפתח מיד — ותראה מול העיניים את התוסף פותח את הטפסים ומקליד לתוכם את כל הציונים והפסיכומטרי!
